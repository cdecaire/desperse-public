# Echoes Design System

> This design context applies **only** to routes under `/echoes` and components in `src/components/echoes/`. It does NOT apply to the main Desperse app. The Echoes visual identity is fully isolated via the `.echoes` CSS scope and `src/styles-echoes.css`.

## Design Context

### Users

Crypto-native creators and collectors who already live in Web3. They expect speed, precision, and respect for their time. They appreciate immersive narratives with world-building depth but will bounce if the experience feels like a generic mint page. They're evaluating trust, rarity, and faction identity — not learning what an NFT is.

### Brand Personality

**Dangerous. Precise. Immersive.**

A signal intercepted from inside a fractured cyberpunk megacity. Classified records, archive breaches, identity instability. Premium but ominous — exclusive, high-touch, never sterile. Editorial but system-driven — curated chaos with clear hierarchy.

### Aesthetic Direction

- **Dark by default** — blue-tinted noir surfaces (`#0D0F12` base), warm stone text (`#CCC8C2`), never pure white or sterile gray
- **Terminal glow** — desaturated teal (`#00BFA6`) as primary interactive accent. Used sparingly for CTAs, active states, and signal moments
- **Heat signatures** — warm amber (`#D4882A`) for warnings, secondary actions, faction accents
- **Organic undertone** — dusty mauve (`#A87CA0`) for human/tertiary elements
- **Faction-coded color system** — five distinct accent colors (Corporate blue, Militia red, Underground teal, Fringe mauve, Zealot amber) used for identity, not decoration
- **Typography-driven** — KH Interference (geometric cyberpunk headlines), Figtree (warm readable body), DM Mono (technical labels and metadata)
- **Atmospheric effects** — scanline overlay (0.02 opacity), film grain noise, glitch corruption bursts. Always subtle, never overwhelming. Performance-safe via `contain: strict` and GPU-composited `clip-path`/`transform`

**References:** Blade Runner UI terminals, Ghost in the Shell data overlays, Cyberpunk 2077 menu screens — filtered through the restraint of Linear/Vercel-grade polish. The atmosphere of a cyberpunk world with the usability of a design tool.

**Anti-references (never do these):**
- Generic NFT mint page (sterile utility, countdown-and-button)
- Clean corporate SaaS landing (over-polished, cold, feature-grid)
- Fantasy lore wiki (purple prose, ornate borders, epic mythology)
- Noisy dystopian collage (chaos without hierarchy, unreadable text on busy backgrounds)
- AI slop tells: gradient text, glassmorphism cards, hero metrics dashboards, neon glow effects, bouncy animations

### Design Principles

1. **Signal over noise** — Every element must earn its presence. Atmospheric effects (scanlines, glitch, grain) stay at whisper-level opacity. If removing something changes nothing, remove it.

2. **Faction identity is structural** — The five faction colors aren't decoration; they're information architecture. Use them consistently for borders, labels, and accents to build faction recognition across every touchpoint.

3. **Progressive immersion** — Surface-level: clean, fast, scannable. One layer deeper: faction lore, trait details, narrative context. Don't front-load complexity. Let curiosity pull users in.

4. **System-native language** — Copy and UI should feel like operating a classified terminal, not reading marketing. Prefer: archive, signal, registry, continuity, breach, sealed, exposure, transmission. Avoid: mint, drop, rare, moon, wagmi.

5. **Motion with purpose** — Scroll reveals, glitch corruption, and hover effects serve the narrative (a fractured signal resolving). Never animate for decoration. Respect `prefers-reduced-motion` absolutely — all animations must have CSS-only disable paths.

## Token Reference

### Color Tokens (CSS custom properties, scoped to `.echoes`)

| Token | Value | Usage |
|-------|-------|-------|
| `--nx-surface` | `#0D0F12` | Base background |
| `--nx-on-surface` | `#CCC8C2` | Primary text (warm stone) |
| `--nx-on-surface-variant` | `#7E8A94` | Secondary text (muted steel) |
| `--nx-primary-container` | `#00BFA6` | Interactive accent (teal) |
| `--nx-secondary-container` | `#D4882A` | Warning/secondary accent (amber) |
| `--nx-tertiary-container` | `#A87CA0` | Organic/human accent (mauve) |
| `--nx-outline` | `#6E7E88` | Borders, dividers |
| `--nx-error` | `#E8A099` | Error states |

### Faction Colors

| Faction | Accent | CSS class |
|---------|--------|-----------|
| Corporate | `#4A90C2` | `.faction-corporate` |
| Militia | `#C24A4A` | `.faction-militia` |
| Underground | `#00BFA6` | `.faction-underground` |
| Fringe | `#A87CA0` | `.faction-fringe` |
| Zealot | `#D4A050` | `.faction-zealot` |

### Rank Tiers

| Rank | Color token | Usage |
|------|-------------|-------|
| Legendary | `--nx-rank-legendary` (#eab308) | Gold |
| Elite | `--nx-rank-elite` (#a855f7) | Purple |
| Rare | `--nx-rank-rare` (#3b82f6) | Blue |
| Uncommon | `--nx-rank-uncommon` (#22c55e) | Green |
| Common | `--nx-rank-common` (#71717a) | Gray |

### Typography

| Role | Font | CSS class |
|------|------|-----------|
| Headlines | KH Interference | `.font-headline` |
| Body text | Figtree | `.font-body` |
| Labels/metadata | DM Mono | `.font-label` |

### Animation Easing

Standard easing across all Echoes animations:
```
cubic-bezier(0.16, 1, 0.3, 1)
```
Spring-like deceleration. Used for reveals, transforms, and state transitions.

## Scope Boundary

This file governs **only** the Echoes experience (`/echoes/*` routes). The main Desperse app has its own design language defined in `CLAUDE.md` under "Design Context" — zinc-950 dark base, purple-heart accent, Figtree typography, content-first social platform aesthetic. The two systems share Figtree and DM Mono fonts but differ in every other dimension.
