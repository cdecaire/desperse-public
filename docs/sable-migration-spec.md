## 0. What Sable is, briefly

Sable (`@cdecaire/sable`, private GitHub Packages registry, source at `D:\dev\sable`) is Desperse's own owned, themeable component library that replaced shadcn/ui + Radix. It ships layout primitives (`Region`, `Columns`/`Col`, `Stack`, `Row`, `AppShell`, `Sidebar`, `SideNav`, `BottomNav`), form primitives (`Field`, `NumberField`, `DateTimePicker`, `Choicebox`, `MultiSelect`, `CheckboxCard`), display primitives (`Note`, `Description`, `Entity`, `StatusBadge`, `DataTable`, `Banner`), a CSS-token design system (semantic color/tone tokens, paired typography utilities, a motion recipe system), and a design-lint enforcement tool (lives in the Sable repo, not this one). Desperse is Sable's only consumer and default theme.

## Tier 4 — Dead dependency cleanup (low risk, good first PR)

### 4.1 Remove now — zero `src/` imports, confirmed dead
`@radix-ui/react-checkbox`, `-dialog`, `-dropdown-menu`, `-popover`, `-select`, `-tabs`, `-toggle`, `-toggle-group` (8 packages). Each verified via `pnpm why <pkg>` to resolve only through a phantom top-level path, with zero actual imports anywhere in `src/`.

### 4.2 Keep for now, but flagged for follow-up
- **`@radix-ui/react-slot`** — the one remaining live Radix import, used in `src/components/ui/category-pill.tsx:37` for an `asChild`/render escape hatch Sable's `CategoryPill` doesn't expose. Sable is Base-UI-powered and has `useRender` internally, but doesn't publicly export a `Slot`/`useRender` composition primitive from its barrel. Two paths: (a) ask Sable to export one, or (b) add `@base-ui/react` (currently only a transitive dep) as an explicit dependency and use `useRender` directly.
- **`lucide-react`** — still used in 5 places despite the app standardizing on FontAwesome via the custom `Icon` component: `src/routes/dev/button-test.tsx:26`, `src/components/profile/LikedPostsModal.tsx:9`, `FollowersModal.tsx:9`, `ActivityModal.tsx:10`, `src/components/feed/CommentSheet.tsx:14`. Migrate these 5 to `@/components/ui/icon`, then drop the dependency. (Note: `@privy-io/react-auth` also transitively pulls its own `lucide-react`, so it won't fully vanish from `node_modules` either way — this is about removing the *direct* dependency and its call sites.)
- **`cn()` duplication** — `@cdecaire/sable` exports its own `cn()`, but `src/lib/utils.ts:38-40`'s version wraps a custom `tailwind-merge` `ds-typography` class-group extension for the paired typography utilities. Do not consolidate onto Sable's `cn` without first confirming it handles that same conflict group, or the `text-heading-*`/`text-body-*` merge behavior will silently break.

### 4.3 Cleanup, separate low-risk PR
- Delete `components.json` (stale shadcn CLI config; its `iconLibrary: "lucide"` was already wrong given the app uses FontAwesome).
- Remove the `shadcn` devDependency and the `shadcn` entry in `.cursor/mcp.json`, once confirmed nobody still runs the CLI manually.
- The "shadcn" string references remaining inside `src/components/ui/*.tsx` (label, calendar, sheet, tabs, toggle, notification-badge, badge, table, card, textarea, input, skeleton, button) are just doc-comments describing the preserved legacy API surface — harmless, no action needed.
